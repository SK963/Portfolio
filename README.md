# Shubham Kumar - Personal Portfolio

A sleek, modern, and highly interactive personal portfolio website built to showcase my journey as a Full Stack Developer. The portfolio highlights my experience, projects, technical skills, and achievements through a beautiful, dynamic interface.

## ✨ Features

- **Modern Tech Stack:** Built using Next.js, React, TypeScript, and Tailwind CSS.
- **Dynamic Animations:** Fluid page transitions, scroll animations, and interactive hover effects powered by Framer Motion.
- **Data-Driven Architecture:** All portfolio content (projects, experience, skills, about me) is powered by a central `src/data/user.json` file. This means updating the portfolio is as simple as editing a JSON file—no complex code changes required!
- **Rich UI/UX:** 
  - Glassmorphic design elements
  - Beautiful neon gradients and glowing highlights
  - Interactive custom skill bars and timeline cards
- **Project Showcase:** A detailed project gallery with filtering, screenshots, and deep links to live demos and GitHub repositories.
- **Fully Responsive:** Beautifully optimized for mobile, tablet, and desktop viewing.

## 🛠️ Built With

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

First, ensure you have Node.js installed. Then clone the repository and run the development server:

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

## 📁 Customizing Content

The core data of the portfolio is completely decoupled from the UI components. To update your name, add a new project, tweak your skills, or update your experience, simply edit:

`src/data/user.json`

The website will automatically reflect your changes with the appropriate styling and icons!
